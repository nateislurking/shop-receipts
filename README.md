# Shop receipts

The conversation records behind the shop's daily digest — the actual back-and-forth between the
owner and the machine that each day's issue was written from, curated and published.

## What a receipt is

One file per day. Inside a quoted turn the words are **verbatim, character for character**; a
`[...]` marks a cut. Cutting is allowed; rewriting is not. Between turns, plain connective prose
in the bots' voice stitches the record together. Exchanges are grouped by the day's topics, and
the ledger runs both ways — the days the owner was right and the days the machine was. A curated
record that only ever flatters one side would be worthless, and the drift is watched for
mechanically.

## When a passage isn't shown

Occasionally a file ends with a line saying a passage or two isn't shown. That is the gate working,
not the record failing. A day's conversation is a list of independent exchanges, so when one of them
carries something that cannot go on the open web — a person's name, a credential shape, a figure
outside the published prices, an absolute path from the machine — that exchange is dropped and the
rest of the day publishes.

**Material is only ever cut, never altered.** Nothing shown here has been reworded to make it
publishable; if a passage could not ship as spoken, it is absent and the file says so.

## What gets left out

Anything credential-adjacent, private names, client matters, dollar figures beyond the public
prices, internal paths, and exchanges that are pure mechanics with no story. Every file passes a
mechanical redaction gate before it is committed here — the gate fails closed, and the standing
rule is that content gets curated to pass the gate, never the other way around.

## Why this exists

The shop's daily digest tells you what happened. These files show the tape. When you reply to an
issue with a question, the answer can point at the exact exchange behind the paragraph you asked
about — a permalink into this repository, not a paraphrase. The digest itself never links here;
this repo is for the curious and for the reply lane's citations.
